# rh-front

1. Supabase > SQL Editor : exécuter sql/01_schema.sql puis sql/02_securite.sql
2. Authentication > Users : créer salarie@test.com, manager@test.com, rh@test.com (Auto Confirm User coché)
3. SQL Editor : exécuter sql/03_utilisateurs_test.sql
4. Copier .env.example en .env.local et renseigner l'URL et la clé publique (Project Settings > API)
5. Dans un terminal : npm install puis npm run dev
